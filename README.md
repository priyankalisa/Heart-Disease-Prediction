# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview

Heart Disease Prediction is a Machine Learning project that predicts whether a person is at high risk or low risk of heart disease using medical data.  
This project is built using Python, Scikit-learn, and Streamlit.

The main goal of this project is to apply Machine Learning techniques in the healthcare domain and create a beginner-friendly real-world prediction system.

---

## 🚀 Features

- Predicts heart disease risk instantly
- Interactive Streamlit web application
- User-friendly and colorful UI
- Real-time prediction system
- Data preprocessing and feature scaling
- Machine Learning model training and evaluation

---

## 📁 Dataset Features

The model uses important medical attributes such as:

- Age
- Maximum Heart Rate
- Oldpeak
- Fasting Blood Sugar
- Chest Pain Type
- Exercise Angina
- Resting ECG
- ST Slope
- Gender

---

## 📈 Evaluation Metrics

The model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
